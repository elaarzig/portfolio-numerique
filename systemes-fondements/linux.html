📘 Présentation de Linux

Linux est un système d'exploitation libre et open source. Il permet de gérer les fichiers, les dossiers et les ressources de l'ordinateur.

💻 Les commandes Linux

Commande Rôle
pwd Afficher le répertoire actuel
ls Afficher les fichiers et dossiers
cd Changer de répertoire
mkdir Créer un dossier
touch Créer un fichier
grep Rechercher un texte dans un fichier
