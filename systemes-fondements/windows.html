📘 Présentation de Windows

Windows est un système d'exploitation développé par Microsoft. Il permet à l'utilisateur d'utiliser un ordinateur, d'exécuter des applications et de gérer ses fichiers.

💻 Les éléments du bureau Windows

Élément Rôle
Bureau Espace principal de travail
Menu Démarrer Accéder aux applications et paramètres
Barre des tâches Afficher les applications ouvertes
Explorateur de fichiers Gérer les fichiers et dossiers
Corbeille Conserver temporairement les fichiers supprimés

📂 Les compétences acquises

  • Créer et organiser des dossiers
  • Copier, déplacer et supprimer des fichiers
  • Utiliser l'explorateur de fichiers
  • Utiliser PowerShell
  • Découvrir les paramètres Windows
