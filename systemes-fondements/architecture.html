Accueil Linux Windows Architecture Électronique

📘 Présentation

L'architecture des ordinateurs étudie l'organisation et le fonctionnement des différents composants d'un ordinateur.

🧩 Les composants principaux

Composant Rôle
Processeur (CPU) Exécuter les instructions et traiter les données
Mémoire RAM Stocker temporairement les données utilisées
Disque dur (HDD) Stocker les données de manière permanente
SSD Stocker les données avec une mémoire flash
Carte mère Relier les différents composants

🔌 Les périphériques

  • Clavier : saisir du texte
  • Souris : déplacer le curseur
  • Écran : afficher les informations
  • Imprimante : imprimer des documents

🎯 Mes compétences

  • Identifier les composants d'un ordinateur
  • Comprendre le rôle du processeur
  • Différencier RAM et mémoire de stockage
  • Comprendre le rôle de la carte mère

🚀 Mon objectif

Comprendre le fonctionnement interne d'un ordinateur et le rôle de chacun de ses composants.
