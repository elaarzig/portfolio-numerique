Découvrir le Prompt Engineering

Le Prompt Engineering est l'art de formuler des instructions claires et précises pour obtenir de meilleurs résultats avec l'intelligence artificielle.

Les éléments d'un bon prompt

Rôle

Définir le rôle de l'intelligence artificielle.

Format

Préciser la forme de la réponse.

Indiquer les limites à respecter.

Mes trois cas pratiques

Cas 1 : Apprendre Python

Prompt initial

Explique Python.

Résultat obtenu

Réponse générale sur le langage Python.

Prompt amélioré

Explique les boucles en Python à une débutante, en français simple, avec deux exemples et leurs explications.

Résultat obtenu

Une explication adaptée au niveau débutant avec des exemples de boucles.

Analyse

Le deuxième prompt précise le niveau, le sujet et le format souhaité. Le résultat est donc plus adapté.


Cas 2 : Corriger un code HTML

Prompt initial

Corrige mon code HTML.

Résultat obtenu

Une correction générale du code.

Prompt amélioré

Agis comme un enseignant en développement web. Analyse mon code HTML et CSS, identifie les erreurs et explique chaque correction en français simple sans changer complètement ma structure.

Résultat obtenu

Une correction accompagnée d'explications.

Analyse

Le prompt amélioré précise le rôle, le contexte et les contraintes.


Cas 3 : Préparer un examen

Prompt initial

Donne-moi un examen.

Résultat obtenu

Un examen général sans niveau précis.

Prompt amélioré

Crée un examen de révision en algorithmique pour une étudiante de première année. Propose deux exercices sur les boucles et les tableaux, avec une correction expliquée en français simple.

Résultat obtenu

Un examen organisé avec des exercices adaptés au niveau demandé.

Analyse

Le prompt amélioré précise la matière, le niveau, les exercices et la correction.
