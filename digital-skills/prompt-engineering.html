Découvrir le Prompt Engineering

Le Prompt Engineering est l'art de formuler des instructions claires et précises pour obtenir de meilleurs résultats avec l'intelligence artificielle.

Les éléments d'un bon prompt

Rôle

Définir le rôle de l'intelligence artificielle.

Contexte

Donner les informations nécessaires.

Tâche

Expliquer clairement ce qu'on demande.

Format

Préciser la forme de la réponse.

Contraintes

Indiquer les limites à respecter.

Exemples

Donner des exemples pour guider l'IA.

Mes trois cas pratiques

Cas 1 : Apprendre Python

Prompt initial : Explique Python.

Prompt amélioré : Explique les boucles en Python à une débutante.

Analyse : Le deuxième prompt est plus précis et plus adapté.

Cas 2 : Corriger un code HTML

Prompt initial : Corrige mon code HTML.

Prompt amélioré : Analyse mon code HTML et CSS et explique les erreurs.

Analyse : Le prompt précise le rôle et les contraintes.

Cas 3 : Préparer un examen

Prompt initial : Donne-moi un examen.

Prompt amélioré : Crée un examen d'algorithmique pour débutant.

Analyse : Le prompt précise le niveau et les exercices.

Ma bibliothèque de 5 prompts

1. Comprendre un cours : Explique ce cours en français simple avec des exemples.

2. Réviser : Prépare un QCM de 10 questions sur ce chapitre.

3. Corriger un exercice : Corrige mon exercice et explique mes erreurs étape par étape.

4. Apprendre un langage : Explique cette notion de programmation avec des exemples pour débutant.

5. Préparer une présentation : Prépare un plan de présentation clair et organisé sur ce sujet.
