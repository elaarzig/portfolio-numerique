Accueil Python Langage C

Bienvenue dans le module Langage C

Découvrez mes connaissances et mes activités en programmation avec le langage C.

1. Présentation du langage C

Le langage C est un langage de programmation utilisé pour développer des programmes informatiques.

Il permet de créer des applications et de travailler avec les données et les instructions.

2. Les notions fondamentales

Les variables

Une variable permet de stocker une valeur dans un programme.

Les conditions

Elles permettent d'exécuter des instructions selon une condition.

Les boucles

Elles permettent de répéter plusieurs fois des instructions.

Les tableaux

Ils permettent de stocker plusieurs valeurs du même type.

3. Exemple de programmation en C

Afficher un message

#include <stdio.h>

int main()
{
    printf("Bonjour !");
    return 0;
}

Ce programme affiche le message Bonjour ! à l'écran.

4. Ce que j'ai appris

  • Déclarer des variables.
  • Utiliser les conditions.
  • Manipuler les boucles.
  • Créer et utiliser des tableaux.
  • Écrire des programmes simples en C.

Mon objectif est d'améliorer mes compétences en programmation et de résoudre des problèmes grâce au langage C.
