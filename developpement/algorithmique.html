Bienvenue dans le module Algorithmique

Découvrez mes connaissances et mes activités dans le domaine de l'algorithmique.

1. Présentation de l'algorithmique

L'algorithmique est une discipline informatique qui permet de résoudre un problème en suivant une série d'étapes organisées.

Un algorithme décrit les instructions nécessaires pour obtenir un résultat.

2. Les notions fondamentales

Les variables

Elles permettent de stocker des informations pendant l'exécution d'un algorithme.

Les conditions

Elles permettent de choisir les instructions à exécuter selon une condition.

Les boucles

Elles permettent de répéter des instructions plusieurs fois.

Les tableaux

Ils permettent de mémoriser plusieurs valeurs dans une même structure.

3. Exemple d'algorithme

Calculer la somme de deux nombres

Algorithme Somme

Variables
    a, b, s : entier

Début
    Lire(a)
    Lire(b)
    s ← a + b
    Ecrire(s)
Fin

Cet algorithme demande deux nombres, calcule leur somme et affiche le résultat.

4. Les étapes de résolution d'un problème

  1. Comprendre le problème.
  2. Identifier les données.
  3. Déterminer le traitement.
  4. Écrire l'algorithme.
  5. Vérifier le résultat.

5. Ce que j'ai appris

  • Déclarer et utiliser des variables.
  • Lire et afficher des données.
  • Utiliser les conditions.
  • Manipuler les boucles.
  • Utiliser les tableaux.
  • Résoudre des problèmes informatiques.
