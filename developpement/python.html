Projet 1 : Calculatrice

Description du problème

Créer un programme qui demande deux nombres et une opération mathématique, puis affiche le résultat.

Code source


a = float(input("Donner le premier nombre : "))
b = float(input("Donner le deuxième nombre : "))

op = input("Choisir une opération (+, -, *, /) : ")

if op == "+":
    print("Résultat :", a + b)

elif op == "-":
    print("Résultat :", a - b)

elif op == "*":
    print("Résultat :", a * b)

elif op == "/" and b != 0:
    print("Résultat :", a / b)

else:
    print("Opération invalide")

Explication

Le programme demande deux nombres. Ensuite, il utilise des conditions pour choisir l'opération. Enfin, il affiche le résultat.

Difficultés et solutions

Difficulté : éviter la division par zéro. Solution : vérifier que le deuxième nombre est différent de zéro.

Projet 2 : Jeu de devinettes

Description du problème

Créer un jeu dans lequel l'utilisateur doit deviner un nombre secret.

Code source


import random

secret = random.randint(1, 10)

nombre = int(input("Deviner le nombre entre 1 et 10 : "))

while nombre != secret:

    if nombre < secret:
        print("Le nombre est plus grand")

    else:
        print("Le nombre est plus petit")

    nombre = int(input("Réessayer : "))

print("Bravo ! Vous avez trouvé !")

Explication

La fonction randint choisit un nombre aléatoire entre 1 et 10. La boucle while continue tant que l'utilisateur ne trouve pas le nombre.

Difficultés et solutions

Difficulté : répéter les essais. Solution : utiliser une boucle while.

Projet 3 : Gestionnaire de notes

Description du problème

Créer un programme qui demande plusieurs notes, calcule la moyenne et affiche une appréciation.

Code source


n = int(input("Donner le nombre de notes : "))

somme = 0

for i in range(n):

    note = float(input("Donner une note : "))

    somme = somme + note

moyenne = somme / n

print("La moyenne est :", moyenne)

if moyenne >= 16:
    print("Très bien")

elif moyenne >= 14:
    print("Bien")

elif moyenne >= 12:
    print("Assez bien")

elif moyenne >= 10:
    print("Moyen")

else:
    print("Insuffisant")

Explication

La boucle for permet de saisir plusieurs notes. Le programme calcule leur somme puis divise cette somme par le nombre de notes. Enfin, les conditions affichent l'appréciation.

Difficultés et solutions

Difficulté : calculer la moyenne. Solution : initialiser somme à zéro, additionner les notes et diviser par n.
